# 暖色手绘课堂 PPT

## 设计身份

沿用米白纸面、暖棕文字、细深色边框、少量蓝黄绿珊瑚色点缀。标题和任务清楚，插图负责解释教学内容。页面根据活动安排构图，整套保留一致字体、边距和色彩角色。

先读 [设计参数与版式](references/design-system.md)，再按照用户的主题和受众组织内容。若用户提供现有PPT，以其可见设计为优先基准。保留原文件，另存编辑版。用户后来给出的受众、配色和内容要求优先。

## 内容与受众

每页让学生知道当前要观察、判断、操作或表达什么。一个主任务配一到三个具体提示，完整长提示词和细操作放配套手册。小学到初中混合课堂可在同一项目提供基础和深入任务，由学生选择。

默认先让学生表达已有想法，再向AI提问、判断建议、核对材料并修改。家长参与取决于用户要求。页数、时长、六选三等规则从当前任务读取。

示意图标明“课堂示意”。工具界面、视频、真实作品和访问状态按实际检查结果填写。图片中的文字、拼音、原文和释义需要核对。功能不可用时提供可以真正完成的文字或文件路径。

## 制作方式

1. 用当前可用的演示文稿工具创建可编辑文本和布局。可以从 assets/layouts.pptx 选取版式，或运行 scripts/build_layouts.py 重建模板。脚本依赖 Python 标准库和 officecli，先检查命令可用性。
2. 模板的媒体框是排版位置，正式课件中需要放入对应主题的作品、截图或插图。字体、文本和任务保持可编辑。
3. 插图使用可用的生图或图片来源，遵循 references/design-system.md 的提示词方向。按用户年龄控制童趣程度。每个新主题准备匹配画面，图片保持比例。
4. 同一套课件组合使用作品大图、对话、分镜、字词卡、步骤、检查清单和展示页。相邻页面应体现活动变化。视觉变化来自内容关系和图文比例。
5. 尽量直接修改现有文字和布局。大范围重做时创建新文件或新版本，保持对象层级清楚，避免整页遮盖旧内容导致编辑困难。

## 验收与交付

逐页渲染，检查标题断行、正文大小、图文遮挡、图像裁剪、脚注与页码、任务是否适合受众。发现问题后重新渲染相关页。结构校验不能代替目视检查。

优先删减无关文案，再调整文本框。中文标点不应孤立换行。投屏正文通常24—30px以上，按实际屏幕和阅读距离确认。图片与图注保留适当间隔。

按照用户要求交付可编辑PPT或演示文稿链接。说明仍未验证的视频、工具或作品链接。只有在用户要求时才上传仓库或发布，此Skill本身不授权外部发布。
