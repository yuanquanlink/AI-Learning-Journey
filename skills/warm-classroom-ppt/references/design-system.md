# 设计参数与版式

## 来源与范围

风格来源是用户认可的“presentation(1).pptx”及其六项目精修版。复用其视觉语法，内容根据当前任务重新组织。原课程曾有低龄Q版和小学至初中版本。默认适度手绘与柔和色彩，用户明确要求Q版时增强人物表情与故事性。

## 画布与字号

16:9，1280×720设计坐标。左右留白约65px，顶部标题区约160px，底部操作信号可位于595—656px，页码在670px附近。所有位置是起点，按内容调整。

- 主标题44—50px，封面主题54—66px，Microsoft YaHei或可用的清晰中文黑体。
- 正文26—30px，分区小标题30—34px，图注16—19px。
- 标题深灰或暖棕，正文保持高对比，行距约1.15—1.3。
- 内容区边框约2px，圆角适中。分隔线细，留白比装饰更重要。

## 色彩角色

| 角色 | 色值 |
|---|---|
| 米白背景 | #FFF6E5 / #FFF8E7 |
| 深灰文字 | #282522 |
| 暖棕标题备选 | #493B33 |
| 浅蓝观察、信息 | #A6DAF7 |
| 黄色任务、重点 | #FFD369 |
| 浅绿检查、总结 | #B6E7A9 |
| 珊瑚色提问、提醒 | #FF9A86 |

每页选一至两个重点颜色，其余作为辅助。混龄班可把色彩降饱和，保留角色关系。

## 版式选择

- 封面：左侧课程名和一句目标，右侧一件主题插图。避免无关装饰。
- 作品说明：大图约占内容区60%—65%，旁边一个彩色说明区，包含成果名、用途和下一步。可左右互换。
- 对话：人物或图像占一侧，另一侧错落两段问答，下方给学生一个开放任务。
- 分镜：四格等宽等高，短标签对应原文依据；画面与解释明确对应。
- 字词卡：三张大卡片，字词或概念占主视觉，下方读音、例句或辨析。根据年龄调整知识深度。
- 步骤：三个清楚的步骤有先后关系，错落可轻微，文字基线与间距可读。
- 检查：按文字、画面、依据或可用性列出检查问题，学生可以逐项完成。
- 展示：作品画面或舞台意象配三条讲述问题，给学生表达的空间。

一套中复用这些语法，但让图文比例、方向、颜色和互动形式随着内容变化。

## 插图方向

可用提示词：米白纸张背景，暖棕细线条，柔和蓝黄绿与少量珊瑚色，清楚的主体与动作，教学手绘插画，留出文字区域，画面无文字无商标。小学可增加Q版表情，初中采用更克制的线描或作品画面。

用原文作为画面依据。比如“疑是地上霜”的画面需要说明月光像霜，避免把想象画面当成原文事实。生成的图像仅能证明图像被生成，音频、可点击网页、部署状态需要另行验证。
